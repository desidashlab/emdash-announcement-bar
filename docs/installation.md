## Two steps

1. In your EmDash admin open **Registry**, search for **Announcement Bar**, and click **Install**. It asks for no permissions.
2. Open **Announcement Bar** in the left menu, go to the **Setup** tab, and paste the short block it shows into the head of your base layout, usually `src/layouts/Base.astro`. If someone else built your site, send them that block.

Then type your message on the **Bar** tab, add a link if you want one, and switch the bar on. It appears on the site within a minute. Set a start and end date for a sale or a holiday notice and it comes and goes by itself.
